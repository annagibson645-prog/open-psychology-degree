# The Open Psychology Degree

A free, self-directed psychology degree as a roadmap: 14 sections of open lectures, MOOCs and free textbooks. Pick the classes you want, tick lectures off, and track progress. Everything saves in your browser only.

Live page: https://annagibson645-prog.github.io/open-psychology-degree/

Layout modeled on [Philosophy for Independent Scholars](https://study.philosophypublics.com/). No connection to that site.

`index.html` is generated by `build.py` from the working copy of the page.
